# Canva Typography & Color Systems

## 1. Curated Canva Native Font Pairings

Select a pairing that matches the project's tone—never mix more than 2–3 font families in one design:

| Aesthetic Direction | Display / Headline Font | Body / Supporting Font | Best Use Cases |
| :--- | :--- | :--- | :--- |
| **Editorial & Authority** | `Playfair Display Bold` / `Cinzel` | `Lora` / `Source Serif 4` | Magazines, reports, book covers, cultural events |
| **Modern Tech & SaaS** | `Space Grotesk Bold` / `Plus Jakarta Sans` | `Inter` / `DM Sans` | Pitch decks, product launches, SaaS carousels |
| **Bold Campaign & Social** | `Montserrat ExtraBold` / `Bebas Neue` | `Open Sans` / `Lato` | Thumbnails, flyers, posters, high-energy promos |
| **Minimalist Luxury** | `Cormorant Garamond` / `Bodoni FLF` | `Montserrat Light` / `Canva Sans` | Fashion, hospitality, invitations, brand kits |
| **Corporate & Executive** | `Merriweather Bold` / `League Spartan` | `Source Sans 3` / `Roboto` | Annual reports, whitepapers, B2B one-pagers |

## 2. Readability & Line Measure Rules
* **Print / Multi-Page Documents:** Body copy **`>= 11.0 pt`** with `1.45–1.55` line height. Split wide pages into 2–3 columns to keep line length between **45 and 65 characters**.
* **Presentations (`1920×1080`):** Body copy `18–22 pt`; never pack full paragraphs onto slides.
* **Social Graphics (`1080px`):** Body/caption text `>= 24 px` so text stays legible on mobile feeds.
* **Thumbnails (`1280×720`):** Maximum 3–6 high-contrast words, thick weight, readable even at `160px` mobile preview width.

---

## 3. Color Hierarchy & Contrast Rules
* **60–30–10 Balance:** `60%` clean canvas/background, `30%` structural surface/secondary tone, `10%` high-contrast accent/CTA.
* **Accessible Contrast:** Aim for `>= 4.5:1` contrast for body text and `>= 3:1` for large display type. Prefer deep ink tones (`#111827`, `#1A222C`) over pure `#000000` on light paper tints (`#FAF7EC`, `#F8FAFC`) to reduce harsh visual glare.
* **Brand Alignment:** When the user provides brand colors or a Canva Brand Kit, strictly anchor the palette to those hex codes rather than inventing unrelated colors.
